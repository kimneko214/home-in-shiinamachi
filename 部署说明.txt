我们的小家 — 自部署网页

最简单的部署方法
1. 解压本压缩包。
2. 将根目录的 index.html 上传到你网站的一个目录，例如 /home/。
3. 用浏览器访问你网站的 /home/，或 /home/index.html。

index.html 是单文件版，已经内嵌 CSS、JavaScript、Three.js 和全部照片。无需 npm、编译、数据库或 API 密钥。支持普通静态主机、GitHub Pages 等。建议通过 HTTP/HTTPS 网站访问。浏览器需要支持 WebGL 和 import map。

如果网站设置了严格的 Content-Security-Policy，需要允许本页内联脚本、内联样式，以及 data: 模块和图片；请按你自己的网站策略配置。

source/ 是方便编辑的分文件版本，入口同样是 index.html。若使用这个版本，请将 source/ 内所有文件和子目录一起上传，保持目录结构。

说明
- 自部署文件不含原平台的登录保护，访问权限由你的网站控制。
- 页面包含你提供的家中照片，访客能在“照片与还原说明”中查看它们。
- 电脑记事本仅保存在当前浏览器的 localStorage 中。
- 户型尺寸为图纸与照片比例估算；日照为艺术化模拟。
- 本次导出检查了文件完整性与 JavaScript 语法，未新增浏览器画面测试。

操作：拖动旋转，滚轮/双指缩放；点击空地移动；WASD/方向键控制；点房间单独查看。
